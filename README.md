# Modes of Address

An initial fashion-exhibition website wireframe for FSAD 6451.

## Features

- Exhibition overview with an interactive design sketch → muslin toile → final garment study
- Intent, Construction, and Wear theme pages
- Searchable, filterable object inventory and object detail pages
- Student roles on the About page
- Responsive layouts and placeholder content throughout

## Run locally

No installation or build step is required.

```sh
python3 -m http.server 8765
```

Open http://localhost:8765 in your browser. You can also open `index.html` directly.

## Edit

- `index.html`: document shell and navigation
- `style.css`: typography, palette, and responsive layout
- `app.js`: placeholder data, page rendering, and interactions

The live private Site is https://modes-of-address-fsad6451.chattyanchor2.chatgpt.site.
This repository contains a standalone copy of the website. The original local project retains its Sites hosting configuration.

All object descriptions, student names, and garment illustrations are placeholders, not collection records.
